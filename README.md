# Portafolio personal

Sitio estático organizado en 17 semanas, con una página independiente para cada una y una portada para recorrerlas.

## Uso

Abre `index.html` en un navegador. No requiere instalar paquetes, iniciar un servidor ni tener conexión a internet.

## Personalización

- En `index.html`, cambia «Tu nombre» y agrega tu carrera o programa.
- Las semanas 5–7 y 9–14 incluyen resúmenes temáticos de referencia. Reemplázalos o complétalos con tus propios trabajos, evidencias y reflexiones.
- Las semanas 1–4, 8 y 15–17 están señaladas como pendientes porque no había actividades de esas semanas en el material de referencia.
- Cada semana tiene su propia carpeta `semanaN/index.html`; puedes editar su título, resumen y tarjetas de contenido directamente.
- Los estilos compartidos están en `assets/css/styles.css`; la búsqueda de la portada está en `assets/js/portfolio.js`.

El sitio usa HTML, CSS y JavaScript del navegador, sin frameworks ni recursos cargados desde terceros. Los resúmenes describen temas académicos; no representan servicios o controles empresariales reales.
